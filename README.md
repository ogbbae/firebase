# FIREBASE — пожарная база знаний

Веб-платформа о пожаротушении: справочник РТП, разборы реальных пожаров с пометками достоверности, библиотека, нормативная база, обучение (тесты, карточки, сценарии, калькуляторы ГДЗС), поиск, карта и сравнение пожаров.

Сайт — одна страница `index.html` без сервера. Он собирается из файлов в папке `src/` и публикуется на GitHub Pages автоматически при каждом коммите в ветку `main`.

## Как включить сайт на GitHub Pages

1. Откройте репозиторий на GitHub → **Settings** → **Pages**.
2. В разделе **Build and deployment** выберите **Source: GitHub Actions**.
3. Откройте вкладку **Actions** и дождитесь зелёной галочки у задачи «Публикация на GitHub Pages» (если задача не запустилась — нажмите **Run workflow**).
4. Адрес сайта появится в **Settings → Pages**, обычно это `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Что работает на GitHub Pages и что — только в Claude

| Функция | GitHub Pages (приложение) | Версия в Claude |
|---|---|---|
| Все разделы, поиск, фильтры, карта, сравнение | да | да |
| Тесты, карточки, сценарии, калькуляторы | да | да |
| Темы оформления | да | да |
| Установка как приложение, работа без интернета | да | нет |
| ИИ-помощник | да — через личный ключ посетителя | да — через аккаунт Claude посетителя |
| Избранное, история, результаты тестов | только в этом браузере | в аккаунте, на всех устройствах |
| Админ-панель и комментарии | нет | да |

### ИИ-помощник: кто платит

Владелец сайта за ИИ не платит, и его аккаунт не используется. Каждый посетитель подключает **свой** ключ API Anthropic (console.anthropic.com → API Keys) на странице «ИИ-помощник». Ключ хранится только в браузере посетителя и отправляется напрямую на `api.anthropic.com`; в коде сайта и в репозитории ключей нет. Посетителю стоит задать лимит расходов для ключа в консоли Anthropic.

### Установка как приложение

Откройте сайт в Chrome, Edge или Яндекс Браузере → меню → «Установить приложение» (на iPhone: Safari → «Поделиться» → «На экран Домой»). После установки FIREBASE открывается отдельным окном с иконкой и работает без интернета (кроме ИИ-помощника).

На GitHub Pages нет сервера, поэтому безопасный вход администратора там невозможен: любой пароль в коде страницы можно подсмотреть. Материалы для GitHub-версии добавляются правкой файлов в `src/` (см. ниже).

## Как добавить или изменить материал

Все материалы лежат в файлах `src/`:

| Файл | Что внутри |
|---|---|
| `src/data.js` | источники, справочник РТП, нормативные документы, тесты, карточки, сценарии |
| `src/ru_fires.js` | российские пожары |
| `src/world_fires.js` | мировые пожары и библиотека |
| `src/fires_2025_26.js` | пожары 2025–2026 годов |

Правки можно делать прямо на сайте GitHub: откройте файл → значок карандаша → **Commit changes**. Через минуту сайт пересоберётся сам.

### Пример: новый пожар

1. Добавьте источник в объект `SOURCES` (в начале файла):

```js
my_src1: {title: "Название статьи", org: "Издание", url: "https://...", date: "2026-10-20", type: "СМИ", accessed: "2026-10-26"},
```

2. Добавьте пожар в `FIRES.push( ... )` по образцу соседних записей. В тексте разделов ссылайтесь на источник так: `{{my_src1}}`. Уровень достоверности раздела — поле `s`: `fact`, `official`, `prelim`, `expert`, `none`.

Правило проекта: в разбор попадают только сведения, подтверждённые источником; если данных нет — раздел помечается «Не установлено», а не заполняется догадками.

## Локальная сборка

```bash
python3 build.py      # пересобрать index.html
python3 -m http.server  # открыть http://localhost:8000
```
